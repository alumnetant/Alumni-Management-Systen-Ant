AlumNet: A Web and Mobile-Based Alumni Networking and Tracer System

Design of Software, System Product Processes

The design of AlumNet, focuses on providing an organized, efficient, and user-friendly platform for administrators, staff, clients, and public users. The software design serves as a blueprint to ensure that the system meets functional requirements such as instant registrar-cross matching & graduate verification, digital alumni ID generation, real-time messaging, continuous graduate employment tracer surveys, institutional event management with QR-code ticketing, corporate vacancy posting, and applicant tracking (ATS), while maintaining data security and accessibility:

  • High-Level Design (Architecture): Defines the main modules of AlumNet, including the Authentication & Verification Engine, Alumni Directory & Network Discovery Hub, Direct Messaging & Discussion Lounges, Digital Alumni ID & Credential Vault, Event Management & QR Attendance Scanner, Corporate Job Board & Applicant Tracking System (ATS), and the Administrative Analytics & Conflict Triage Dashboard. It establishes how these modules communicate, handle data, and provide services to different user roles.
  • Low-Level Design (Detailed Design): Specifies the internal workings of each module, including database structures for plots and client records, algorithms for registrar masterlist matching and dispute triage, user interface layouts, and system interactions for notifications, QR code generation, and offline access.

System Product Processes for AlumNet

The development of AlumNet follows structured processes to ensure quality, reliability, and usability:

  1. Requirements Analysis: Gathering and validating requirements from St. Cecilia's College administration, staff, alumni, and employer partners, including graduate identity verification, employment status tracking, institutional event scheduling, job postings, and public accessibility.
  2. System Design: Converting requirements into system architecture and module specifications. This includes database design, interface mockups, and workflow definitions for user interactions and administrative tasks.
  3. Implementation: Developing the system using appropriate technologies, including web-based dashboards for administrators, Android mobile support for clients, and API integration for notifications and verification services.
  4. Testing: Conducting unit, integration, and user acceptance testing to ensure accurate graduate verification, navigation functionality, and system reliability.
  5. Deployment and Maintenance: This phase covers releasing AlumNet to the live environment, including server setup, app deployment, and user training. It also involves regular updates, bug fixes, and feature enhancements to keep the system secure, efficient, and aligned with institutional alumni operations and community needs.
